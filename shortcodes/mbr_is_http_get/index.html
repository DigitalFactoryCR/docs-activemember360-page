mbr_is_http_get

Usage​

This shortcode determines the content to be included based upon the existence of the specified $_GET variable and it's optionally specified value.

Parameters​

ParametersDescription
varThe name of the $_GET variable for whose existence you are checking.
Default: none.
Required: yes.
valA value to which the $_GET variable will be compared to evaluate to true.
Default: none.
Required: no.

Validity​

This shortcode is evaluated for any type of visitor.

Conditional Branching​

[ELSE_is_http_get] conditional branching is supported.

Nesting​

Shortcode nesting is supported: [mbr_is_http_get1] thru [mbr_is_http_get19]
[ELSE_is_http_get1] thru [ELSE_is_http_get19]
[/mbr_is_http_get1] thru [/mbr_is_http_get19]

Examples​

  • Example 1
  • Example 2
  • Example 3

Will display "Test GET is set" if $_GET['test_get'] exists:

[mbr_is_http_get name='test_get']
Test GET is set
[/mbr_is_http_get]

Will display "Test GET is set" if $_GET['test_get'] exists. Otherwise will display "Test GET is NOT set":

[mbr_is_http_get name='test_get']
Test GET is set
[ELSE_is_http_get]
Test GET is NOT set
[/mbr_is_http_get]

Will display "Test GET is set to 123" if $_GET['test_get'] exists AND its value is equal to 123. Otherwise will display "Test GET is NOT set to a value equal to 123":

[mbr_is_http_get name='test_get' val='123']
Test GET is set to 123
[ELSE_is_http_get]
Test GET is NOT set to a value equal to 123
[/mbr_is_http_get]

API​

Note

There is no ActiveMember360 API function equivalent for this shortcode. Please use standard PHP functions.
