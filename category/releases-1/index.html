Releases

Learn about each ActiveMember360 release:

📄️ 1.4.0 (2017-06-01)

- BuddyPress extension for ActiveMember360 which enables automatic protection and/or access to BP Groups based on tags.

📄️ 1.3.0 (2017-05-19)

- Added tag-based pricing for WooCommerce simple products and simple subscriptions, enabling you to specify alternate prices based on a member’s tags.

📄️ 1.2.23 (2017-05-08)

- Added an option to specify a maximum password length.

📄️ 1.2.22 (2017-04-23)

- Fixed an issue which could certain WooCommerce shopping cart messages to not be displayed.

📄️ 1.2.21 (2017-04-06)

- Fixed an issue which could cause long delays for sites with over 100 automations.

📄️ 1.2.20 (2017-04-04)

- Added “abandoned cart” functionality to our WooCommerce extension. This feature lets you assign tags based on cart abandonment as a whole and/or for each product in the abandoned cart.

📄️ 1.2.19 (2017-03-30)

- Added a new parameter to the mbr_autologin module which, when used, instructs the auto-login process to retry / wait for up to a given number of times at 1-second intervals.

📄️ 1.2.18 (2017-03-15)

- Added a new BadgeOS award / achievement step based on a member’s ActiveCampaign tags, whereby holding a given tag would fulfill a step requirement.

📄️ 1.2.17 (2017-02-21)

- Modified the “mbr_autologin” module to enable JVZoo and ClickBank secure logins based on validated transaction data. The module autodetects JVZoo and ClickBank settings and handles the autologin automatically.

📄️ 1.2.16 (2017-02-18)

- Modified the “mbr_autologin” module to enable a ThriveCart secure login based on validated transaction data. The module autodetects the ThriveCart settings and handles the autologin automatically.

📄️ 1.2.15 (2017-02-15)

- Added a “populate” parameter for the [mbr_form] shortcode to automatically populate form fields.

📄️ 1.2.14 (2017-02-07)

- Added ActiveCampaign actions for WooCommerce subscription reactivation after a an “on hold” status.

📄️ 1.2.13 (2016-12-06)

- There was an issue with the LearnDash extension displaying excerpts even where the “Excerpt only with permissions” checkbox was set. This has been fixed.

📄️ 1.2.12 (2016-11-30)

- Added several redirect rules to accommodate various 3rd party themes and plugins and prevent unwanted 404 situations.

📄️ 1.2.11 (2016-11-24)

- Fixed an issue with WooCommerce failed login message.

📄️ 1.2.10 (2016-11-21)

- Fixed 2 issues in our recent WordPress menu builder extension.

📄️ 1.2.9 (2016-11-18)

- Added a new extension for “Contact Form 7”, adding integration between CF7 and ActiveCampaign.

📄️ 1.2.8 (2016-11-16)

- Added a new extension for the WordPress menu builder, adding integration for user membership and login status.

📄️ 1.2.7 (2016-11-12)

- Resolved a conflict with combinations of themes/plugins which could hide metaboxes normally visible when editing pages, posts, courses, etc.

📄️ 1.2.6 (2016-11-09)

- WordFence’s security plugin attempts to load an outdated version of the “datatables” javascript library while ActiveMember360 loads the current version of the same library. WordFence uses variables and function that are no longer available in the up-to-date version, causing a number of javascript errors. This ActiveMember360 release provides a “go around” mechanism, enabling WordFence to load their outdated version of the library (P.S. WordFence has since released a new version where they resolve this issue). Belated thanks to Steve Dimmick for notifiying us of the original issue. Good eye, Steve!

📄️ 1.2.5 (2016-11-08)

- Fixed an issue with “Menu Visibility” not displaying correctly in the WordPress menu builder.

📄️ 1.2.4 (2016-11-08)

- Added optional support for custom post types. Any 3rd party post types can now be integrated via “Utilities” -> “Custom Post Type”.

📄️ 1.2.3 (2016-11-06)

- Added support for “course completion” ActiveCampaign actions (automations, tags, lists) for Memberoni

📄️ 1.2.2 (2016-10-18)

- Fixed an issue where shortcodes entered into menu links were being prefixed with “http//”.

📄️ 1.2.1 (2016-10-11)

- Fixed an issue where users logging in with their “old” user names (i.e. not their email address) would not get their passwords captured and updated in ActiveCampaign.

📄️ 1.2.0 (2016-10-11)

- ActiveMember360 now supports PHP 7.0

📄️ 1.1.3 (2016-09-30)

- ActiveMember360 now prevents “protected” WooCommerce products from appearing in product category and product tag views of the shopping cart. In category views, empty categories are suppressed and the actual product count is modified to reflect the correct number of products in the given category.

📄️ 1.1.2 (2016-09-13)

- Added LearnDash “Course” product type integration with ActiveCampaign.

📄️ 1.1.1 (2016-09-12)

- Added bbPress user profile integration with ActiveCampaign.

📄️ 1.1.0 (2016-09-09)

- This version provides further integration between WooCommerce actions and ActiveCampaign.

📄️ 1.0.6 (2016-08-19)

- This version auto-populates WooCommerce forms with user data in the following order order of priority, based on availability of data:

📄️ 1.0.5 (2016-08-19)

- Fixed a redirect problem with posts not redirecting properly when post level redirects where defined.

📄️ 1.0.4 (2016-08-17)

- Added additional options for the WooCommerce/ActiveCampaign integrations.

📄️ 1.0.3 (2016-08-07)

- This version adds support for two new ActiveCampaign webhooks, “contacttagadded” and “contacttagremoved”.

📄️ 1.0.2 (2016-07-29)

- This version includes ActiveMember360’s new WooCommerce integration for ActiveCampaign.

📄️ 1.0.1 (2016-07-14)

- Fixed an issue with ActiveMember360 excerpt metaboxes on posts.

📄️ 1.0.0 (2016-07-12)

- This is the initial release. Beginning with this release, a valid license is required. See//activemember360.com/pricing/.
